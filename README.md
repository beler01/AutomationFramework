# Selenium Automation Framework

A Java-based Selenium automation testing framework built using Maven and TestNG.

## 🚀 Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- PageFactory
- Apache POI
- Rest Assured
- Log4j2
- Extent Reports
- Git & GitHub
